# Лабораторная работа 2: Создание смарт контракта и взаимодействие с ним

Смарт-контракт Poster (Solidity, Hardhat 3) в сети Sepolia и dApp на Next.js + web3.js: публикация постов с тегом, просмотр всех постов, фильтр по тегу.

- Контракт: https://sepolia.etherscan.io/address/0x48F1EB9f061602fC46e8fb7f63Bb4706DE11db5D#code.

## Структура

- `poster-contract/` - контракт, тест, модуль деплоя
- `poster-ui/` - интерфейс

## Запуск интерфейса

Нужны Node.js 22+ и MetaMask (сеть Sepolia, немного Sepolia ETH для газа).

```bash
cd poster-ui
npm install
npm run dev
```

Открыть http://localhost:3000.

## Как пользоваться

1. Нажмите **Connect** и подтвердите подключение в MetaMask. Приложение переключит кошелёк на Sepolia.
2. **Публикация:** введите текст и тег, нажмите **Опубликовать**, подтвердите транзакцию в MetaMask. Через 10-30 секунд нажмите **Обновить**.
3. **Просмотр:** в списке видны текст, тег и адрес автора для всех постов из контракта.
4. **Фильтр:** введите тег в поле фильтра (точное совпадение). Чтобы вернуть все посты, очистите поле.

Примечание: тег хранится в блокчейне как хеш keccak256 (`indexed string`), поэтому фильтр работает только по точному совпадению, а текст тега показывается для значений, введённых в текущей сессии.
